# LARA — Intelligent Internal Support Agent | Latram Shop

> A **ReAct agent** that assists the support and operations team of Latram Shop
> (a LATAM-based e-commerce with coverage across Latin America and North
> America): it answers questions about internal policies citing the exact
> source **and** queries business metrics from sales data — in **English or
> Spanish** — without anyone opening a single PDF or spreadsheet.

## 📋 Project overview

Latram Shop's support team handles hundreds of daily cases that require
consulting 5 internal policy documents (refunds & returns, affiliate program,
shipping, payment methods, and product warranty) plus the operational orders
dataset. **LARA** (Latram Assistant for Retrieval & Analytics) centralizes both
sources behind a single natural-language interface.

The agent decides on its own which tool to use for each question:

- **Policies & processes** → RAG over the 5-PDF corpus, citing the consulted
  section and explicitly declining when the answer is not in the documents
  (anti-hallucination guardrail).
- **Data & metrics** → safe analytical tools over the orders dataset (no
  arbitrary code execution on the server).
- **Visualization** → chart generation from the data.

Since the company operates across the Americas, employees ask questions in
both **Spanish and English**; LARA retrieves from the Spanish-language policy
corpus regardless of the question language (multilingual embeddings) and
replies in the language of the question.

## 🏗️ Solution architecture

<!-- TODO Day 2: final Mermaid diagram -->

```
Employee question (EN / ES)
        │
        ▼
  LARA (ReAct agent — LangChain)
        │
        ├── Tool: search_policies ──► Chroma (5 PDFs) ──► answer + citation
        ├── Tool: sales_metrics   ──► safe functions over orders.csv
        └── Tool: generate_chart  ──► matplotlib ──► image
        │
        ▼
  FastAPI  ──►  Docker  ──►  OCI Compute (Always Free)
```

**Design decisions**

- *Aligned data*: `orders.csv` is a reproducible sample dataset whose
  vocabulary is consistent with the policy documents (payment methods,
  shipping zones), enabling cross-source questions (data + policy).
- *No public Python REPL*: metrics are exposed through fixed, safe functions —
  never through LLM-generated code execution.
- *Multilingual by design*: local multilingual embeddings
  (`multilingual-e5-small`) allow English questions over Spanish documents.
- *Observability*: every agent reasoning trace is logged to LangSmith.

## 🧰 Technologies & tools

| Layer | Technology |
|---|---|
| Language | Python 3.11+ |

## 🚀 How to run the project

```bash
# 1. Clone and install
git clone <repo-url> && cd latram-support-agent
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2. Configure credentials (all providers have free tiers)
cp .env.example .env   # then edit with your API keys

# 3. Build the vector index
python -m src.app.build_index

# 4. Chat with the agent in the console
python -m src.app.cli
```
